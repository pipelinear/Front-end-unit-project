Panda Study Tool
Website: pandastudytool.vercel.app (were advertising this)
Panda Study Tool is a web app designed to help students manage schoolwork, learn material, and build projects in one place. Instead of needing to search through different websites for everything, Panda brings AI tutoring, classes, planning, educational videos, and coding tools together.
Home
The home page explains what Panda is and gives students access to the main tools. Panda can help with different subjects and languages, while teachers can set rules that control how the AI works in their class.
Classes
Students can join classes where teachers can post assignments, announcements, and other information. Panda can organize the student's assignments and allow them to work on them through the platform. Teachers can also view learning diagnostics, such as what concepts students are struggling with, and use that information to improve future assignments.
Chat
Panda Chat is an AI tutor that uses the Socratic method. It does not simply give students answers when they ask for them. Instead, it asks questions, gives hints, explains concepts, and uses scaffolding to help students figure out the solution themselves.
Plan
Panda automatically creates a to-do list using assignments from the student's classes. Students can see what is due, what they should work on next, and what they have already completed. This helps students stay organized without having to manually keep track of everything.
Watch
Watch is a built-in educational video section using YouTube. It is designed to make learning more interactive and less boring than only reading from an AI. Schools can set restrictions so Panda only allows appropriate and educational content.
Build
Build is a lightweight browser-based IDE where students can create websites and applications. It includes HTML, CSS, JavaScript, file management, previews, and AI coding assistance. The AI can explain errors and help students understand their code instead of simply doing the work for them.
Privacy and Safety
Panda is designed with student privacy in mind. Teachers can receive useful learning diagnostics and assignment information, but student conversations should not automatically be visible to teachers. Panda will also have clear Terms of Service, Privacy Policies, data rules, and school-controlled safety settings.
Page Diagrams
Each page will have a diagram showing its layout, buttons, interactive features, and how the different parts connect. The diagrams will also show what students, teachers, and Panda can access on each page.
